# Event_Booking_App
Event Booking App - Go Backend System  An open-source Event Booking and Seat Allocation System built in Go. This project provides a robust backend for creating virtual events, managing seat inventory, and handling reservations. It's designed as a showcase of building clean, efficient, and scalable distributed systems.  Key Features:  Create and manage virtual events.  Dynamic seat allocation and reservation system.  RESTful API for frontend clients.  Built with performance and concurrency in mind using Go.
